# 🎬 Theater Ticket Booking System

A full-stack MERN application for online movie ticket booking with secure authentication, seat selection, booking management, and admin dashboard.

---

## 🚀 Features

- User Authentication (JWT)
- Role-Based Access Control (RBAC)
- Movie Management
- Showtime Management
- Seat Booking
- Booking History
- Admin Dashboard
- Responsive Design

---

## 🛠 Tech Stack

Frontend
- React.js
- Tailwind CSS
- Axios

Backend
- Node.js
- Express.js

Database
- MongoDB

Authentication
- JWT

Deployment
- Vercel
- Render

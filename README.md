# 🎬 Theater Ticket Booking System

A full-stack **MERN (MongoDB, Express.js, React.js, Node.js)** web application for booking movie tickets online. Users can browse movies, view show details, select seats, and book tickets through a modern, responsive interface. The application includes secure JWT authentication, role-based access control, and RESTful APIs.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/RahulPrajapati60/Theater-ticket-booking-system.git
```

Move into project directory

```bash
cd Theater-ticket-booking-system
```

---

## Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```

---

## Backend Setup

```bash
cd Backend
npm install
npm run dev
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the Backend folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

CLOUDINARY_CLOUD_NAME=your_cloud_name

CLOUDINARY_API_KEY=your_api_key

CLOUDINARY_API_SECRET=your_api_secret
```
